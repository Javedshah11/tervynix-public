This roadmap shows the current direction of Tervynix.

Tervynix is under active development, so priorities may evolve as the platform grows.

---

## ✅ Completed

### Core Workspace
- Project workspace foundation
- Monaco code editor
- Multi-file tab management
- Autosave
- Manual save support
- Workspace persistence

### Authentication & Ownership
- Authentication
- Login/logout flow
- Project ownership protection
- Authenticated project access

### Terminal
- Integrated terminal
- Multiple terminal sessions
- Terminal session management
- Terminal reattachment support
- Shell process tracking

### Runtime
- Process Manager
- Port Manager
- Runtime event infrastructure
- Runtime WebSocket communication
- Runtime History foundation
- Task discovery and execution
- Process start/stop/restart controls
- Preview and open-port functionality

---

## 🚧 In Progress

### Backend Modernization
- TypeScript-first architecture
- NestJS modular backend
- Fastify HTTP adapter
- PostgreSQL migration
- Drizzle ORM integration

### Runtime Reliability
- PTY reliability improvements
- Windows ConPTY stability
- Terminal runtime testing
- Runtime History end-to-end validation

### Architecture
- Clear domain boundaries
- Repository contracts
- Backend service separation
- Legacy architecture migration

## Long-Term Vision

Tervynix aims to become a complete development environment where developers can:

**Code → Run → Debug → Manage → Collaborate → Deploy**

from one integrated workspace.
