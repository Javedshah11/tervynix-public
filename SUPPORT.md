# Support Tervynix

Tervynix is an independently developed software project focused on building a modern developer workspace for coding, terminals, runtime management, AI-assisted development, and deployment.

The project is currently under active development.

## How You Can Support Tervynix

You do not need to contribute financially to help the project.

You can support Tervynix by:

- ⭐ Starring the public repository
- Sharing Tervynix with other developers
- Reporting bugs
- Suggesting features
- Participating in discussions
- Testing future releases
- Providing technical feedback
- Contributing documentation or ideas

Every contribution helps the project improve.

## Financial Support

Financial support will help with areas such as:

- Development infrastructure
- Hosting and cloud services
- Testing environments
- Domains and project services
- AI infrastructure
- Developer tooling
- Future public releases

Official sponsorship and supporter options will be added as they become available.

## Help Build the Future of Tervynix

The long-term goal is to create an integrated development environment where developers can:

**Code → Run → Debug → Manage → Collaborate → Deploy**

from one workspace.
